# Personal Finance Manager

## 📌 Project Overview

Personal Finance Manager is a Python-based command-line application used to track daily expenses, generate reports, and analyze spending patterns.

The system uses Object-Oriented Programming (OOP), CSV file handling, data persistence, and a menu-driven interface.

---

## 🚀 Features

* Add new expenses
* View all expenses
* Search expenses
* Category-wise summary
* Monthly expense reports
* Generate report file
* CSV data storage
* Error handling and validation
* Backup functionality

---

## 🛠️ Technologies Used

* Python
* CSV Module
* Object-Oriented Programming (OOP)

---

## 📂 Project Files

* `main.py` → Main program entry point
* `expense.py` → Expense class definition
* `file_manager.py` → CSV file operations
* `menu.py` → Command-line interface
* `reports.py` → Report generation and analysis
* `utils.py` → Validation functions
* `expenses.csv` → Expense data storage
* `report.txt` → Generated report file

---

## ▶️ How to Run

1. Install Python
2. Open terminal in project folder
3. Run the following command:

```bash
python main.py
```
